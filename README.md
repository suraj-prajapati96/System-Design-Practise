# 🚀 System Design Practice

A collection of **System Design** concepts and their implementations in **C++**. This repository is created to strengthen my understanding of backend engineering and distributed systems by implementing popular system design algorithms from scratch.

- ✅ Consistent Hashing
- ✅ Fixed Sliding Window Rate Limiter

- ✅ SHA-256 Hashing Algorithm
- 🔜 Token Bucket Rate Limiter
- 🔜 Leaky Bucket Algorithm
- 🔜 Load Balancer
- 🔜 Distributed Cache
- 🔜 Bloom Filter
- 🔜 URL Shortener
- 🔜 Message Queue
- 🔜 Distributed Lock
- 🔜 LRU Cache
- 🔜 API Gateway

## 📖 Implemented Concepts

### 🔹 Consistent Hashing
- Virtual hash ring implementation
- Efficient server addition and removal
- Minimal key redistribution

### 🔹 Fixed Sliding Window Rate Limiter
- Request limiting based on time windows
- Thread-safe implementation
- Useful for API rate limiting

### 🔹 UUID Version 1
- Time-based UUID generation
- Node identifier
- Clock sequence handling

### 🔹 SHA-256
- Complete SHA-256 hashing implementation
- Message padding
- Compression function
- Final 256-bit digest generation

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/suraj-prajapati96/System-Design-Practice.git
```

Move into the project directory

```bash
cd System-Design-Practice
```

Compile any program

```bash
g++ filename.cpp -o output
```

Run

```bash
./output
```

or on Windows

```bash
output.exe
```
